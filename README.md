# Bulk Certificate Generator

Submit one batch of recipients and get one PDF certificate per recipient,
generated by a background worker. Design decisions: [docs/design.md](docs/design.md).

> Status: Phase 1 (project foundation). Job APIs are not implemented yet.
> The full README comes in Phase 8.

## Quick start

Requires Docker with Compose v2.

```bash
docker compose up --build
```

This starts PostgreSQL, Redis, a one-off migration container, the API, and
the Celery worker. Then open:

- Health check: http://localhost:8000/health
- Swagger UI: http://localhost:8000/docs

## Tests

```bash
docker compose run --rm --build tests
```

## Dependencies

`requirements.in` and `requirements-dev.in` list direct dependencies.
`requirements.txt` and `requirements-dev.txt` are generated lock files; do not
edit them by hand. To re-lock after changing an `.in` file:

```bash
docker run --rm -v "$PWD":/src -w /src python:3.12-slim sh -c "pip install -q uv && uv pip compile requirements.in --universal --python-version 3.12 -o requirements.txt && uv pip compile requirements-dev.in --universal --python-version 3.12 -o requirements-dev.txt"
```
